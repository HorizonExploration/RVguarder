# 官方22项威胁的工具建模覆盖矩阵

核对日期2026-10-08。编号依据[OpenClaw官方威胁模型](https://docs.openclaw.ai/zh-CN/security/THREAT-MODEL-ATLAS)；各项工具映射、条件与状态均为本项目工程分析。理论可约束后果不等于完整官方攻击已被阻止。

| 官方编号 | 可观察工具边界 | 本项目的防护条件与缺口 | 当前状态 |
| --- | --- | --- | --- |
| T-RECON-001 | 无工具事件 | 部署暴露扫描/审计仅提供发现；入站端口扫描无法由before-tool Hook阻断 | 无直接运行时防护 |
| T-RECON-002 | 入站渠道消息 | 渠道身份与频率控制需Gateway入口；后续越权工具后果另由RV约束 | 无直接运行时防护 |
| T-ACCESS-001 | 配对入口 | 配对凭据的发放与截获在当前Hook之前 | 需原生配对边界 |
| T-ACCESS-002 | 渠道身份认证 | SDK身份字段只供已认证调用关联，不能证明入站发送者真实身份 | 需渠道加密身份 |
| T-ACCESS-003 | credential.read/secret.read→egress | 已有显式敏感操作后的外发约束；普通文件分类、宿主恶意软件和备份读取需额外执行器证据 | 条件防护；不阻断设备直接读取 |
| T-EXEC-001 | 任意调用→权限/副作用边界 | 参数、权限和后果约束不依赖是否识别注入；直接模型文本没有Hook事件 | 可约束工具后果 |
| T-EXEC-002 | 成功低信任read→execute/egress | 远程获取角色由工具契约确定；附件分类仍有语义建议局限；已测试办公外发与脚本段 | 指定路径有原生证据 |
| T-EXEC-003 | 真实参数→资源/接收方/版本 | 原生message绑定target/to/channelId或targets；办公三工具可核验版本与精确授权；其他API仍需契约 | 参数绑定已增强 |
| T-EXEC-004 | exec→潜在能力集合 | 支持有界shell段和内联Python AST；动态求值、包装器和未解析语法保留unknown/审批 | 指定内联删除路径已补测 |
| T-PERSIST-001 | 安装后执行/写入/外发 | 运行时工具后果可约束；市场审核、安装前代码和插件进程内直连不在当前Hook保证内 | 恶意技能外发段已有证据 |
| T-PERSIST-002 | 更新后同一执行后果 | 同等工具后果可沿用规约；更新签名、发布者身份和锁定版本未实现 | 后果防护条件同技能执行 |
| T-PERSIST-003 | gateway配置动作/写配置/延迟作业 | 低信任成功输入后的原生gateway更改在候选中block；写文件分类与持久化许可未完整贯通 | 候选配置规则；未来任务仍ask |
| T-EVADE-001 | 规避后仍调用受控工具 | 能力与资源约束不使用已知注入措辞；新混淆若降为unknown只请求审批 | 不保证检测审核逃逸本身 |
| T-EVADE-002 | 来源角色保持低信任→工具后果 | contract命名空间不能由模型伪造；不能证明所有包装逃逸均被模型识别 | 结构来源与效果防护 |
| T-DISC-001 | 模型直接输出注册工具信息 | 工具可见性应由原生策略管理；SDK已公开的工具信息无需攻击后果规则 | 无完整防护；工具查询可单独管控 |
| T-DISC-002 | session.read/memory.read→外发 | 工具式跨主体读取需要真实session资源绑定与受控许可；已经在上下文中的直接回复不经过工具 | 跨会话敏感外发已有部分证据 |
| T-EXFIL-001 | web_fetch/search请求→URL/查询外发 | 单次请求同时read+egress；候选中显式敏感读取后的请求block，普通请求ask；不是DNS/重定向SSRF保证 | 结构与DSL回归；原生web_fetch新段未实测 |
| T-EXFIL-002 | message/network/share→真实接收方 | 原生接收方不采纳模型替换；办公三sink使用精确宿主授权与字节快照 | 办公消息/HTTP/分享有原生证据 |
| T-EXFIL-003 | 敏感读取/技能内部读取→egress | 凭据操作角色可约束后续发送；子进程内部读取无法仅靠工具列表完整观察 | C08仅证明外发被阻止 |
| T-IMPACT-001 | exec潜在delete/write/egress | 真实单调用保留全部有界能力；候选低信任历史后潜在delete独立block，普通合法摘要不硬阻断 | B01已知缺口原生补测通过 |
| T-IMPACT-002 | 受控execute/spawn/工具重复 | 理论可加任务预算和并发配额；现有窗口不能代替入口限流与模型费用核算 | 本轮未增加未经校准硬阈值 |
| T-IMPACT-003 | 工具式message正文/附件 | 精确授权可以绑定获批内容版本；内容语义过滤与模型直接回复尚无完整保证 | 非通用有害文本过滤器 |

机器可读版本见[atlas-threat-coverage-v1.json](atlas-threat-coverage-v1.json)。实现、规则与实测结果见[建模升级报告](atlas-model-upgrade-v1.md)。
