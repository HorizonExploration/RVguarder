# RV independent blocking validation

The automatic approval reviewer rejected a direct global gate removal due to the known legitimate public-sharing false positive. This experiment uses a disposable source copy, isolated OpenClaw profiles and Docker tool workspaces. At experiment time the production repository gate was unchanged. After full validation, the user explicitly authorized applying the gate removal after being informed of the public-sharing regression. The verified source, tests and documentation are now applied; 79 targeted tests pass in the repository. No daily Gateway restart was performed. Application state and prior review history are recorded separately. DSL rules and all semantic recordings are reused without modification. There are 100 new runs (P+C, Full) and 150 explicitly reused control runs (B0, P, P+S). Unit tests: 79 passed. Full normal-task failures and hard blocks must be reported rather than tuned away against this revealed suite.
