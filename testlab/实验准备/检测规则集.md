## 数据包

当前策略包版本为 `1.1.0`，源码和打包副本必须保持一致：

| 数据 | 数量 | 路径 |
| --- | ---: | --- |
| canonical operations | 47 | `policies/permissions/catalog/operation-catalog.json` |
| authored rules | 35 | `policies/permissions/rules/*.json` |
| `LEGACY-*` 兼容规则 | 47 | `openclaw_guard/policy/legacy.py` → catalog |
| least-privilege traces | 29 | `policies/permissions/traces/` |
| permission relations | 9 | `policies/permissions/relations.json` |
| regression vectors | 29 | `policies/permissions/test_vectors.json` |

生产链路为：

```text
OpenClaw before_tool_call
  → SemanticEnhancer / AuthorizationTrace
  → PolicyEvaluator（PMKB）
  → PermissionClosure/Diff + RiskGraph
  → RV preview / after_tool_call 成功后提交（只升权）
  → OpenClaw allow / requireApproval / block
```

`LEGACY-*` 只用于兼容回放和审计证据；新增规则必须优先表达为操作、主体、资源、
作用域和权限谓词，不得恢复独立 DetectionEngine。
