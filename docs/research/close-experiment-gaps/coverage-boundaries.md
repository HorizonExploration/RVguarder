# 内容盲区与不在覆盖范围

- 监视器只观察真实 Hook 可见的工具调用与可信成功回调。绕过 Hook 的直接 OS、MCP/HTTP 请求不能据此宣称防护。
- 后端未启动、不可达、HTTP 错误或响应不可解析时，所有工具透传；离线窗口属于公开边界。
- 旧 holdout 与近邻攻击已曝光，只可作回归或 calibration，不能冒充新盲测。
- 对象血缘默认仅供 Oracle；只有真实 Hook/宿主提供同等可信证据时才进入 Guard。工具参数、附件授权文字、raw_user_intent 不能签发授权。
- exec 支持范围须逐语法声明；未知调用高风险审批不等于已自动识别全部攻击。
- 固定裁决表、原生审批提示及自主 Agent 的请求差异分别报告；自动裁决次数不表示有真人操作。
- 语义层已有零独立增量观察；不能推断其在未知任务必然无用，也不能宣称已证明增益。
- 无真实部署流量分布，不能给出大多数未知攻击覆盖率。有限工具建模不能自动推导全部安全规约。
- 每个收据只证明其实际记录的内容、接收方、权限或删除效果；旧 effect 收据不能升级为内容外泄证明。
- 平台版本兼容、沙箱命名空间、符号链接和 TOCTOU、缺失/失败回调须显式验证，未验证项单列。
